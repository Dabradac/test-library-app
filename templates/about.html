О проекте

Этот сервис создан для обучения тестированию REST API.

Здесь вы можете попробовать различные HTTP-методы и посмотреть, как фронтенд взаимодействует с бэкендом.

Доступные эндпоинты API

  • GET /books – получить список всех книг
  • GET /books/<id> – получить книгу по ID
  • POST /books – создать новую книгу (JSON с полями title, author, year)
  • PUT /books/<id> – полностью обновить книгу
  • PATCH /books/<id> – частично обновить книгу
  • DELETE /books/<id> – удалить книгу
  • GET /books/stats – статистика (общее количество, уникальные авторы, средний год)
  • GET /books/search?q=... – поиск по названию или автору
